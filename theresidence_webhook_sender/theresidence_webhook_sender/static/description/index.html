🔗 The Residence - Webhook Sender

Module Odoo pour envoyer automatiquement des webhooks vers l'API externe de The Residence.

v1.0.0 Odoo 19.0 Python 3 Webhooks API Integration

✨ Fonctionnalités

📤 Envoi automatique
Les webhooks sont envoyés automatiquement lorsque des événements se produisent dans Odoo.
🔄 Retry intelligent
En cas d'échec, le système réessaie automatiquement avec un backoff exponentiel.
📊 Monitoring complet
Suivez tous vos webhooks avec des vues Kanban, des logs détaillés et des statistiques.
⚙️ Configuration flexible
URL, API key, timeout, nombre de retries... tout est configurable.
🔒 Sécurité
La clé API est stockée de manière sécurisée et les droits d'accès sont gérés.

📋 Événements supportés

  • Commandes: confirmée, prête, terminée, annulée
  • Réservations: approuvée, rejetée, annulée, check-in
  • Abonnements: activé, en pause, repris, annulé
  • Membres: mis à jour

🚀 Installation

  1. Installer la dépendance: pip install requests
  2. Copier le module dans le dossier addons d'Odoo
  3. Redémarrer Odoo
  4. Aller dans Apps > Update Apps List
  5. Rechercher "The Residence - Webhook Sender"
  6. Cliquer sur Install
⚠️ Important: Après installation, vous devez modifier votre module existant pour utiliser theresidence.webhook.service au lieu de theresidence.webhook.

Consultez le fichier INTEGRATION_EXAMPLE.py pour plus de détails.

🔧 Configuration

Une configuration par défaut est automatiquement créée avec :

  • URL: https://api.laresidence-abidjan.com
  • API Key: Pré-configurée
  • Timeout: 10 secondes
  • Max retries: 5 tentatives
  • Delays: 1, 2, 4, 8, 16 secondes

Vous pouvez modifier cette configuration dans :
Webhooks The Residence > Configuration
